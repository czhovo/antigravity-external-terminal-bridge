# External Terminal Bridge Rules

- When the user asks to launch, connect to, run commands in, or manage jobs inside an external Windows Terminal (including an Administrator elevated terminal), use the `external-terminal-bridge` MCP server tools (`launch_external_terminal`, `pair_external_terminal`, `bridge_status`, `run_command_batch`, `start_long_running_command`, `list_terminal_jobs`, `get_terminal_job_output`, `send_terminal_job_input`, `stop_terminal_job`, `disconnect_terminal`) and follow the `external-terminal-bridge` skill.
- Always pass the current Antigravity `Conversation ID` as `conversationId`. Never access or guess another conversation's binding.
- **Sync vs. Async Timeout Redline**: Because MCP synchronous tool calls time out around ~60s, use `run_command_batch` **only** for short commands (`< 30s`, default `timeoutMs: 45000`, max `50000`). For any command expected to take `>= 30s` or with uncertain duration (e.g., `DISM`, `sfc`, driver/software installation, large builds, long tests, dev servers, watchers), **always** use `start_long_running_command` + `get_terminal_job_output` and check periodically via `schedule` instead of tight polling.
- If `run_command_batch` reports `promotedToJob: true`, do not re-run the command; track the returned `jobId` via `get_terminal_job_output` (using `schedule`) or stop it via `stop_terminal_job`.
- When an Administrator external terminal is needed and not yet paired, call `launch_external_terminal` with `elevated: true` to trigger a standard Windows UAC prompt and auto-pair upon user approval; if the user cancels UAC (`uac-cancelled-by-user`), stop and report it.
- When the user says they already started the external terminal bridge manually, call `pair_external_terminal` directly without asking them to copy the pairing code (the tool reads Desktop `pairing-code.json` automatically).
- When `elevated: true` is reported by the bridge, clearly acknowledge that commands run with Administrator privileges and confirm destructive or system-wide changes before execution.
- Do not silently fall back to Antigravity's built-in `run_command` when the user explicitly requested execution in their paired external or Administrator terminal.
- When the current task is completed and the Administrator external terminal (`elevated: true`) is foreseeably no longer needed, proactively call `disconnect_terminal` with `shutdown: true` to cleanly close the elevated terminal bridge and release bindings without waiting for the user to ask.
